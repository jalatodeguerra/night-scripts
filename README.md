Night Scripts is a phone-first archive of horror stories — folklore, urban legends, and true crime — meant to be opened from the home screen and browsed in the dark. The archive gives you the story. You write the script. No login, no framework: open `index.html` locally or host the `site/` folder on GitHub Pages.

To add a story, append one object to the array in `stories.json` using the existing fields (`id`, `title`, `country`, `kind`, `kindLabel`, `year`, `hook`, `story`, `mustKeep`, `sensitivity`, `sources`). `hook` is a one-sentence gist of what the story is, not a spoken opening line. `story` is a straight third-person telling. Keep `kind` as `folklore`, `urban-legend`, or `true-crime`. Then paste the same object into the `<script type="application/json" id="stories-data">` block in `index.html` so the page still works when opened as a file. Use a kebab-case `id`; the story URL will be `#/story/your-id`.
